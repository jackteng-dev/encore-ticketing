## 已知問題

單實例 Redis AOF everysec 不是 HA／零資料遺失；M3 未驗吞吐或 cluster。join/poll 才補位，沒人呼叫無推播。五個 room keys 同 hash slot，但單票種仍熱 key；最多220活躍、1000有 TTL membership，每人最多20 retired ID，最近 join 最大等待期後30分鐘清理，room idle一小時。超過保留期或完全 state loss 後原UUID不保證永久去重，GET不自動重建資格。

Redis CHECK 與 PG commit 不是跨系統原子交易；確認資格後斷線不回滾已成功 PG 訂單。Redis只控制入口，尚無Redis票額扣減／MQ流程。身份 owner+sessionVersion 綁定，退出／停用後舊資格等短期限自然釋放。員工session仍在API記憶體，多API前需改共享；最終模型為本機展示，不宣稱正式售票或真收款。

自有 API／preview 已停止，僅本輪 scope PG/Redis containers、volumes、network 已 down -v；25432/26379/19110/15180 全部關閉、自有 scope 資源零殘留。其他作品與服務未動。沒有精確 context/usage 介面；已分段保存，這輪不擴大到M4。
